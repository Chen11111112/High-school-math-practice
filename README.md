## 怎麼用

- 依年級進入資料夾，檔名就是該份練習卷的主題。
- `北商小考` 是小考卷；`手寫詳解` 是手寫後掃描的詳解。
- 詳解看不懂，直接問我本人。
- GitHub 不一定能預覽 PDF，建議下載後再開。

### 高一上

數與式、絕對值、無理數與分點公式、指數、對數、常用對數、多項式、因式定理與餘式定理、二次與三次函數、直線方程式、直線與圓、排列組合。

### 高一下

集合與邏輯、數列、級數、遞迴與數學歸納法、排列組合、二項式定理、數據分析、銳角三角函數、廣義角與極座標。

### 高二上

指數與對數、弧度與圖形、和角公式、倍角與半角、三角疊合、向量表示法、向量內積。

### 高二下

矩陣、線性變換、三元一次方程組、外積與三階行列式、空間向量、空間坐標、空間中的平面與直線、條件機率。
